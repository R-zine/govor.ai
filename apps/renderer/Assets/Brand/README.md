# govor.ai host icon

`govor-icon.png` is the source artwork used by the Godot project and
`govor-icon.ico` is the Windows multi-resolution derivative (16, 24, 32, 48, 64, 128, and
256 pixels).

The artwork was generated specifically for govor.ai with OpenAI's built-in image generation on
2026-10-25. It is not a third-party logo. The final prompt was:

> Use case: logo-brand. Asset type: Windows desktop application icon for govor.ai, a privacy-first
> local English speaking tutor. Primary request: create one original minimal icon mark combining a
> rounded speech bubble with a subtle audio waveform or speaking cue, suggesting conversation and
> language learning. Style/medium: clean vector-like flat icon, geometric, modern, adult and calm.
> Composition/framing: single centered mark, strong square silhouette, generous transparent
> padding, readable at 16x16 and 32x32. Color palette: mint teal #73DBC3 and deep charcoal #0E1513,
> with off-white only if needed for separation. Constraints: genuinely transparent background; no
> text, no letters, no flags, no microphone hardware, no gradients, no shadows, no mockup, no
> border around the canvas, no watermark; original design only.
