# Built-in photographic backdrops

The four built-in lessons use locally bundled, freely redistributable photographs as 2D
backdrops. They are never downloaded at runtime. Godot scales and crops each image behind the
selectable 3D teacher; installed data-only environment recipes continue to use the separate
bounded primitive renderer.
