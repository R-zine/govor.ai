# 2026-11-03 release 0.1.21 deployment

## Scope

This record covers packaging the current source as matching portable Windows and signed Android
release artifacts, checking the packaged host against the installed local models, updating the
USB-connected physical phone without clearing application data, and cold-starting the updated
Android Activity. It is build, package, host-readiness, signature, update-compatibility, and
Activity-startup evidence. It is not a pairing, media, lesson-creation, teacher-selection,
Bulgarian intelligibility, or end-to-end lesson result.

## Environment

- Development/host PC: Windows process build 10.0.26200, Europe/Kiev.
- Source commit: `3a29e49` (`feat: add phone lesson creation and align Bulgarian voices`).
- Physical phone: realme RMX3939 / RMX3939EEA, authorized over USB for ADB. Its serial is omitted.
- Release: 0.1.21, Android version code 22, application ID `ai.govor.app`.
- Signer certificate SHA-256:
  `b7022cb8bbcc0a4828cf73e5ef958e1b431ccce697020577c4a502a66ec59843`.

## Evidence boundary

The run verifies matching host/client packaging, signature and update compatibility, installed
version metadata, host entry points, local model availability, and Android Activity startup. It
does not start the host gateway or renderer, scan the pairing QR, transfer WebRTC media, return
microphone audio, create a lesson, or judge whether the Bulgarian teacher presentation is natural
and intelligible. The phone Activity was left open for the user; no host server, PC audio, or
Android media playback was left active.
