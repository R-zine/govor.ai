# 2026-11-02 release 0.1.18 build and deployment

## Scope

This record covers building the matching portable Windows host and signed Android release from the
current selectable-teacher source, updating the USB-connected physical phone without clearing its
application data, validating installed metadata, and cold-starting the Android Activity. It is not
an end-to-end pairing, network, media, acoustic, teacher-presentation, or lesson acceptance run.
