# 2026-11-03 release 0.1.20 deployment

## Scope

This record covers rebuilding the current source as matching portable Windows and signed Android
release artifacts, validating the portable host against the existing local model store, updating
the USB-connected physical phone without clearing application data, and cold-starting the updated
Android Activity. It is build, package, host-readiness, update-compatibility, and Activity-startup
evidence. It is not a pairing, media, lesson, teacher-selection, speech-quality, or host-menu
usability run.

## Environment

- Development/host PC: Windows process build 10.0.26200, Europe/Kiev.
- Source commit: `b35bf3f` (`feat(host): expose content and update tools`).
- Physical phone: realme RMX3939 / RMX3939EEA, authorized over USB for ADB.
- Release: 0.1.20, Android version code 21, application ID `ai.govor.app`.
- Signer certificate SHA-256:
  `b7022cb8bbcc0a4828cf73e5ef958e1b431ccce697020577c4a502a66ec59843`.

## Evidence boundary

The run verifies matching host/client packaging, signature and update compatibility, installed
version metadata, host entry points, local model availability, and Android Activity startup. It
does not start the host gateway or renderer, scan the pairing QR, transfer WebRTC media, return
microphone audio, execute a lesson, assess Bulgarian speech, exercise teacher selection, or
visually confirm the new host management menu. The phone Activity was left open for the user; no
host server, PC audio, or Android media playback was left active.
