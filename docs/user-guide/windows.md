# Windows user guide (development status)

The current host offers only a loopback deterministic mock for developers. Run
`./scripts/dev.ps1 -Mode mock`; it does not use models, cloud services, or learner data. It is not
LAN-enabled and cannot yet teach a lesson on a phone.

The final launcher, pairing UI, model setup, firewall guidance, renderer startup, clean shutdown,
and installable distribution remain future milestones.
